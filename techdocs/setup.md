## Krav
- Docker Desktop
- Git
- VS Code (anbefalt)

## klone repo
- git clone https://github.com/KristianTalgo/wombo
- cd wombo

## starte serveren
- docker compose up --build

## åpne app
- http://localhost:8000

## stoppe siden
- docker compose down

## kjøre db-migrasjoner
- docker compose exec web python3 migrate.py
